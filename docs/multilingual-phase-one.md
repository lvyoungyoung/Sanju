# 三句多语言第一期范围

日期：2026-10-13

状态：第一期实施范围；尚未实现或发布。语言方向已按产品讨论确定，本文将其细化为开发与验收要求。

范围调整：第一期界面仅支持简体中文和英文；学习语言、翻译与讲解语言及 10 个学习组合保持原定范围。

## 1. 目标与完成标准

让中文用户能学习更多外语，同时让海外用户通过中英文界面使用三句，以自己熟悉的语言获取翻译与讲解，学习英语或其他外语。

继续围绕现有核心体验：自己的照片 → 两组三句场景表达 → 翻译与朗读 → 收藏 → 讲解与复习。

第一期完成意味着：本文列出的 10 个学习组合都能走通上述流程，界面、内容、朗读、学习记录和云同步保持一致。只有生成模型能够输出某种语言，不算已经支持该语言。

## 2. 支持范围

### 2.1 三种语言设置

| 设置 | 含义 | 第一期开通范围 |
| --- | --- | --- |
| 界面语言 | 按钮、页面、错误提示等界面文案 | 简体中文、英文 |
| 讲解语言 | 新生成句子的翻译、AI 讲解及例句翻译所用语言 | 简体中文、英文、西班牙文、日文、法文 |
| 学习语言 | 照片生成的目标句子、朗读和复习所用语言 | 英语、西班牙语、日语、法语 |

三种设置分别保存。界面语言不限制可选的学习组合；可选学习语言由讲解语言决定。

例如，日本用户可以使用英文界面、日文翻译与讲解来学习英语。西语、日语、法语的学习内容和讲解支持，不代表提供这些语言的界面。

简体中文在第一期用于界面、翻译和讲解，不作为学习目标。繁体中文专门适配留待后续版本。

### 2.2 首批开放的 10 个学习组合

| 讲解语言 | 可学语言 | 组合数 |
| --- | --- | --- |
| 简体中文 | 英语、西班牙语、日语、法语 | 4 |
| 英文 | 西班牙语、日语、法语 | 3 |
| 西班牙文 | 英语 | 1 |
| 日文 | 英语 | 1 |
| 法文 | 英语 | 1 |
| **合计** | | **10** |

第一期不开放其他交叉组合或同语讲解的独立学习模式。现有英语用户仍能保留英文界面、英文 AI 讲解等已具备的能力；不得因新组合限制而删除旧能力或阻止历史内容访问。

新组合的上线顺序：保留并验证现有中文学英语 → 西语相关组合 → 日语相关组合 → 法语相关组合。允许分批内部测试；第一期正式范围仍包括全部 10 个组合。

### 2.3 首期教学变体

| 学习语言 | 首期标准 |
| --- | --- |
| 英语 | 延续现有美式英语与朗读偏好 |
| 西班牙语 | 以拉美常用表达为默认，选用匹配的朗读口音；不提供地区切换 |
| 日语 | 标准日语，默认适合日常交流的礼貌表达；提供可开关的假名读音辅助 |
| 法语 | 以法国常用法语和匹配口音为默认；不提供地区切换 |

生成、翻译、例句和朗读采用同一套语言约定。具体音色及供应商通过质量验证后确定，不在本文预先承诺供应商能力。

## 3. 用户使用流程

### 3.1 设置与首次使用

- 界面默认跟随系统支持的语言；系统语言不在首期范围内时回退英文，并允许手动选择。
- 新用户确认“用什么语言看翻译和讲解”以及“想学什么语言”。讲解语言默认跟随界面；不支持的学习组合不展示为可选项。
- 既有用户首次升级保留原有界面与英语学习体验，不强制重新引导，不自动重写历史内容。
- 修改讲解语言后，如果当前学习语言不在支持组合中，让用户重新选择学习语言；不能静默切换。
- 登录用户的学习语言、讲解语言与各语言难度偏好支持账号同步；未登录时保存在本机。界面语言保持设备偏好。

### 3.2 照片生成

- 生成前能看到当前学习语言和难度，减少用错语言消耗次数的情况。
- 一次生成只针对一种学习语言，保留现有两组三句、照片分类和表达用途，不一次生成四种语言。
- 句子、翻译和辅助读音均围绕同一张照片、同一难度，保持自然且适合学习。
- 各语言沿用现有难度档位的用户认知，但独立定义句长、词汇和语法要求；不能把英语的单词数限制直接用于日语。
- 点击生成时固定本次的学习语言、讲解语言、教学变体和难度。切换设置、重试或断线恢复均不改变这次请求的内容。
- 维持现有生成次数计费单位：一张照片的一次成功生成扣一次；切换设置和恢复结果不扣次，生成失败不扣次。

### 3.3 回忆、收藏和语言切换

- 每条回忆保存生成时的学习语言与翻译语言；每条句子的语言身份保持稳定。
- 回忆保留跨语言浏览，能够识别内容属于哪种语言；收藏和复习提供明确的学习语言筛选。
- 收藏列表、待学数、开始学习入口及学习页使用一致的当前语言范围。查看其他语言的历史内容不会自动修改下一次生成的语言。
- 复习队列按学习语言区分，每轮只练一种语言；已学次数、当天进度和再次复习记录不因切换语言而重置。
- 现有每日新学习上限继续按用户合计计算，不因新增四种语言而扩大四倍。
- 切换偏好只影响未来生成及按需请求的讲解，不自动翻译或覆盖旧回忆。历史回忆原有翻译始终可读。

### 3.4 AI 讲解

- 沿用现有按需流程：打开详情只读取缓存，用户点击 AI 解析才生成。
- 保留 1–4 个重点词或短语的结构；解释使用所选讲解语言，例句使用该句的学习语言，例句翻译使用所选讲解语言。
- 不再固定生成英文例句和中文翻译。
- 对历史句子只允许请求已支持的讲解组合；不支持时保留已有内容，并提示选择可用的讲解语言。现有中英文英语讲解继续兼容。
- 切换讲解语言不修改原句、原有翻译或学习进度；缺少新语言缓存时需再次主动请求。
- 延续现有讲解不消耗照片生成次数、独立限流的规则。

### 3.5 朗读

- 四种学习语言均须具备可用于学习的自然朗读；新增语言首期至少提供一种通过校对的默认音色。
- 保留现有英语音色选择；新增语言不要求首期提供相同数量的音色。
- 朗读请求、预加载、缓存和系统回退均识别学习语言、教学变体及音色，避免错误复用音频。
- 云端朗读失败时只能回退到正确语言的可用系统音色；没有合适音色则明确提示无法播放，不使用英语声音读其他语言。

### 3.6 收藏复习

- 继续使用选词／短语填空，不新增独立课程体系。
- 英语保留已有规则；西语和法语适配重音字符、省音、标点及合适的挖空单元。
- 日语按词或短语划分练习单元，适配助词与活用，不能按空格拆分或只识别英文字母。
- 日语假名辅助不进入原句正文，不破坏句子标识、缓存或选词答案；填空处的读音提示不能直接泄露答案。
- 不因语言切换或升级改变已经保存的收藏与学习结果。

## 4. 海外用户体验的必要配套

- 中英文界面覆盖新用户引导、生成、回忆、收藏、学习、讲解、设置、登录、购买及主要错误状态；小组件和通知的界面文案同样只支持中英文，展示的学习内容保留其原有语言。
- 调整产品文案中只描述“学英语”的通用入口，让它与当前学习语言一致。
- App Store 的介绍、关键词、截图文案与实际上线能力匹配，明确区分“中英文界面”和“多语言学习及讲解”；支持网址、隐私说明及购买说明提供中英文。
- 在英语、西语、日语和法语用户的代表性网络环境中验证登录邮件、照片上传、生成、朗读和购买恢复。记录失败率与耗时，不仅用本地网络判断海外可用性。
- 第一期开通语言不预设必须迁移服务器。出现实际网络问题后，另行评估基础设施方案。

## 5. 数据与兼容性要求

当前仓库已有中英文界面与讲解入口，但句子模型和生成输出仍使用固定的 `english` / `chinese` 字段；填空按英语空格拆词，系统朗读回退固定为 `en-US`。因此本期涉及完整学习链路，不能只增加界面翻译文件。

- 建立明确的学习语言、翻译／讲解语言、教学变体和语言偏好模型；具体字段与接口方案在实施时设计。
- 历史回忆按“英语原句＋简体中文翻译”兼容读取；历史英文讲解缓存保留，不批量重新生成旧内容。
- 数据迁移保留原句、稳定句子 ID、收藏、图片、学习进度、余额与生成任务恢复关系。
- 登录同步、访客合并、去重和删除操作都须保留语言信息，不能把不同语言的记录误认为同一句。
- 缓存区分账号、原文、学习语言、讲解语言、教学变体、音色及适用的内容版本；按缓存类型使用相关维度。
- 旧客户端继续收到其能理解的英语内容；同一账号在新客户端生成其他语言后，旧客户端不得将其误读为英语、覆盖或删除。兼容方式须在接口设计中明确并验证。
- 生成、持久化、恢复和后台元数据链路对新增语言一致处理；无效语言或不支持组合在模型调用和扣次前拒绝。

主要涉及模块：生成与模型回退、生成结果持久化及恢复、句子讲解、语音、本地模型与云同步、收藏学习队列、偏好设置、界面本地化和旧客户端兼容。

## 6. 本期不做

- 韩语、德语、中文、葡萄牙语等新增学习目标。
- 表格以外的任意语言互学，以及新的同语学习模式。
- 西班牙文、日文、法文界面，以及繁体中文专门本地化；同一语言的多地区课程或口音切换。
- 日语五十音等系统入门课程、考试课程、语音评分、开放式 AI 对话。
- 一张照片同时生成多种语言，或批量把历史回忆翻译为新语言。
- 自动改写历史原句、重置学习记录，或修改购买套餐与订阅体系。
- 仅为了本期扩语种开发 Android、迁移海外服务器或重做整体导航。

## 7. 开发与发布顺序

| 阶段 | 交付内容 | 进入下一阶段的条件 |
| --- | --- | --- |
| 1. 多语言基础 | 数据结构、偏好、接口、历史兼容、语言筛选 | 现有英语流程及旧客户端兼容通过 |
| 2. 西语 | 中文／英文用户学西语，西语用户学英语；西文翻译与讲解 | 三个新增组合完整走通并通过内容与语音校对 |
| 3. 日语 | 中文／英文用户学日语，日语用户学英语；日文翻译与讲解、假名及复习规则 | 三个新增组合通过，日语分词与读音可用于学习 |
| 4. 法语 | 中文／英文用户学法语，法语用户学英语；法文翻译与讲解 | 三个新增组合通过 |
| 5. 发布验证 | 全部 10 个组合、中英文界面、海外网络及商店物料 | 下列首期验收项目全部完成 |

发布顺序遵循 [后端发布流程](backend-release-process.md)：完成本地检查后提交并推送任务变更；数据库迁移先于依赖它的 Edge Functions 部署，再验证客户端。

实施时预计需要新的数据库迁移，并改动生成、讲解、朗读等后端能力；确切迁移文件、函数清单及代理配置需求在代码完成后逐项列出。本文不构成部署授权。本次仅新增范围文档，无需执行迁移或部署。

## 8. 首期验收

- [ ] 10 个学习组合均完成：首次选择 → 照片生成 → 翻译 → 朗读 → 收藏 → AI 讲解 → 复习 → 再次打开。
- [ ] 每种新增学习语言覆盖全部难度档位、两组句子和常见照片场景；由具备相应语言能力的校对者检查自然度、含义、难度与读音。
- [ ] 西语、法语的重音、省音与答案显示正常；日语的分词、助词、活用及假名不造成错误或答案泄露。
- [ ] 中英文界面在主要页面无遗漏或截断；两种界面均可选择五种翻译／讲解语言并使用对应学习组合。多语言内容支持大字体与 VoiceOver 语言识别，服务器错误映射为中英文界面提示。
- [ ] 切换三种语言设置、切后台、断网、恢复任务、重启 App 后，不出现错语生成、串语音频、重复扣次或学习记录丢失。
- [ ] 验证访客使用、注册／登录合并、多设备同步、退出再登录及账号隔离。
- [ ] 历史回忆、收藏、学习进度与英语音色偏好正常；旧客户端不会误读或破坏新语言数据。
- [ ] 海外代表性网络下完成登录、生成、朗读、购买恢复验证；语音供应商的目标语言质量、可用性及成本已经确认。
- [ ] 商店宣传仅列出已验收的语言与能力；发布记录包含版本、迁移、函数及实际验证结果。

功能完整性和语言质量是发布门槛。真实市场需求通过上线后的分组数据验证，不用模型自评或下载量替代。

## 9. 上线后观察

按“讲解语言 → 学习语言”记录首次生成完成率、生成后收藏率、七日内复习留存、购买转化、生成／朗读失败率、耗时和单位成本。学习事件同时保留事件发生时的语言组合，不能用用户后来修改的偏好回填。

实施时先统一事件与指标口径。样本量不足的组合标注样本量，不据此直接判断语言需求高低；结合用户反馈决定第二期先做韩语、德语、中文学习，还是增加更多英语学习者的母语支持。

## 10. 选择依据与资料

排序综合学习需求、照片场景适配、现有用户延伸和实现成本，不等同于按全球使用人口排序，也不代表付费增长预测。

- [多邻国 2025 年语言报告](https://blog.duolingo.com/2025-duolingo-language-report/)：英语、西语、法语、日语位于其平台学习热度前四；英语在 154 个国家排名第一。仅作为平台需求信号。
- [塞万提斯学院西语学习者统计](https://cervantes.org/es/sobre-nosotros/sala-prensa/notas-prensa/estudiantes-espanol-lengua-extranjera-todo-mundo-crecen)：约 2,421 万学习者，主要集中在美国、欧盟和巴西；教育统计不等同于 App 可获取用户。
- [OIF 2026 年法语报告](https://www.francophonie.org/sites/default/files/2026-04/Synthese_rapport_Langue_francaise_dans_le_monde_2026.pdf)：约 5,100 万法语外语学习者；与其他机构的统计口径不同。
- [Statcounter 日本移动操作系统统计](https://gs.statcounter.com/os-market-share/mobile/japan)：研究时读取的 2026 年 9 月 iOS 占比约 60.5%，属于移动网页访问统计，仅辅助判断 iOS 平台适配，不能推断付费意愿；链接会随月份更新。
- 本地现状依据：`三句/AppModel.swift`、`三句/SentenceStudyQuestion.swift`、`三句/SpeechService.swift`、`supabase/functions/generate-memory-v2/content.ts`、`supabase/functions/explain-sentence/content.ts`，以及 [句子讲解](sentence-explanation.md)、[语音](mimo-speech.md) 和 [项目交接](project-handoff.md) 文档。
