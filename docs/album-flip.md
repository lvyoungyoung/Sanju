# 翻一翻

“回忆”页底部的悬浮入口，打开全屏英语相册。只有存在非空英文句子时才显示入口。

## 浏览与反馈

- 所有照片的所有句子都可以出现，不局限于收藏或某个句子分组。
- 显示一张照片、一句英文；中文翻译点击展开。长句可以在文字区域上下滚动。
- 左滑“再看看”，右滑“熟悉了”；底部按钮提供相同操作。
- 卡片跟随横向拖动倾斜，下一张逐步抬起；距离不足回弹，达到阈值或快速甩动则飞出。
- 垂直拖动不记录反馈；退出过程中或连续点击不会重复提交一次反馈。
- 尽量避开刚出现的照片和句子。“再看看”的原句在若干张之后重现，并在下次进入时保留较高抽取权重。
- “熟悉了”按手机当前时区、跨自然日逐步提升熟悉等级（最多 4 级）；同一天反复右滑不叠加。左滑重新降到 0 级。
- 未反馈权重 12，“再看看”权重 24；熟悉 1～4 级的近期权重分别为 4、2、1、1。距离最近右滑达到 1、3、7、14 个自然日时，熟悉句子的权重回升到 6，保留回访机会。这是轻量推荐规则，不代表已通过学习测验。
- 可以一直翻，没有固定每日上限。只有一张照片或一句话时也可继续浏览。

## 朗读与图片

- 每张卡片稳定出现后自动朗读一次，复用现有 MiMo 流式朗读、音色设置、音频缓存及系统语音回退。
- 快速切卡、关闭页面、切换账号或进入后台都会停止旧朗读。回到前台不会突然重新自动播放。
- 顶部可关闭本次浏览的自动朗读，底部仍可手动重播。
- 本轮固定保留当前句和接下来 5 句；提前检查这 5 句的当前音色缓存，缺失时逐句静默生成。滑过一张后保留已排好的后续顺序，只在队尾补一张。
- 当前句的音频请求优先，拿到当前音频后可在播放过程中准备后续音频。如果翻到正在预加载的句子，复用已收到的音频及后续流，不再次请求。
- 预加载仅在“翻一翻”页面运行；退出取消，退后台或断网暂停。切账号取消旧队列，切音色只为当前窗口更新音频，不提前生成所有音色。
- 预加载失败不发声、不显示错误、不修改生成次数或学习记录；失败后短暂冷却，避免快速翻页反复消耗 TTS 配额。手动朗读保留原来的请求与系统语音回退。
- 使用已有账号／环境／文本／音色隔离的本地音频缓存；预加载仍占用云端 TTS 用量。生成描述、保存回忆及扣次数链路不触发预加载。
- 当前卡片和下一张卡片按需获取图片，复用现有图片下载去重与账号校验。
- 图片解码在后台执行，限制最长边为 1280 像素；图片失败可以重试，不阻断翻看句子。

## 数据边界

- 浏览反馈先保存在本机 UserDefaults，按环境和登录账号隔离；未登录使用 guest 范围。
- 登录后通过独立的 `album_flip_progress` 表和 `sync_album_flip_feedback` RPC 同步。每句仅保存最新反馈、反馈时间、熟悉等级、最近右滑时间和幂等事件 ID；不修改收藏、填空学习记录、掌握度或生成次数。
- 本机保留待上传操作队列，上传成功后清除；网络失败不阻断滑动。2 秒合并窗口、每批最多 100 条；滑动只上传，不逐次拉取全量历史。进入相册、切账号登录、回前台及恢复网络时刷新云端记录。
- 云端按反馈时间和事件 ID 处理重复、乱序和并发请求；旧操作不会覆盖较新的反馈。多设备同时使用时以最新反馈为准，离线旧操作不会追溯重算已被新反馈覆盖的历史。
- 匿名回忆迁移成功后，按句子标识或内容映射一起迁移对应翻看记录；不同账号不会自动共享。退出登录保留该账号未发送的记录，重新登录继续上传。删除句子、回忆或账号时云端级联清理。
- 进入页面时建立本轮句子集合，下次打开时读取最新回忆。
- 拉取云端反馈不打乱已经预加载的当前句和后 5 句，只影响后续入队。

## 部署

- 执行 migration：`20260925000000_add_album_flip_progress.sql`，先 staging 验证，再 production。
- 无需更新 Edge Function、密钥或代理。旧客户端不调用新表/RPC，不影响原有学习接口。
- 数据库迁移未部署时，新客户端仍可本地翻看，待上传记录会保留；需要部署迁移后才能验证跨设备同步。

- `AlbumFlipTests` 覆盖全部六句、空数据、重复数据、单句循环、避免连续相同照片、原句重现、反馈隔离、重复提交、手势阈值及图片解码。
- `AlbumSpeechPrefetchTests` 覆盖五句窗口、串行缓存、命中跳过、重复文本去重、窗口滚动、快滑取消、流式接管、退出／断网／切账号／切音色及失败冷却。后续五句只保留数据，仍仅挂载当前与下一张图片视图。
- 使用挂载的 SwiftUI 视图进行大小屏幕、深色模式、长句和完整页面截图测试。ScrollView 的内容不能仅依靠 ImageRenderer 验证。
- 回归运行 `SpeechAudioTests` 和 `MemoryImageLoaderTests`。
- `AlbumFlipHistoryTests` 覆盖跨天/时区、左滑重置、权重、离线队列、同步重试、账号隔离、匿名迁移和上传分批；`scripts/tests/album-flip-history.test.ts` 在本地 PostgreSQL 引擎验证 RPC、RLS、幂等、批次原子性及级联清理。
