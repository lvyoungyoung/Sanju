# 翻一翻

“回忆”页及分类详情可打开全屏句子相册；生成结果可只浏览本次照片的六组对话。沿用现有语言上下文，新卡片是一张对应照片和一组 A/B 对话，翻译点击展开；历史单句仍单独成卡。

## 对话卡片（2026-10-16）

- 新生成使用 `dialogue_tabs_v1`：场景表达、画面描述各三组对话，共十二句、六张卡片。每句保留独立 ID，`dialogue.index` 在组内从 0 开始，`dialogue.turn` 区分 A/B。
- 只在同一照片、同一展示组内配对，且必须恰好有 A/B 各一句。单句旧数据或不完整本地数据不丢弃、不跨组拼接。服务端拒绝不完整的新对话。
- 浏览以一组对话为单位，保留同图分散、实际历史顺序和前后浏览。单张照片每轮先三组场景表达，再三组画面描述，接可继续滑动的轮次间隔卡。
- 生成结果及照片详情将两句放在同一卡片内，每句可以独立播放、收藏。翻阅卡片的收藏按钮与双击操作收藏整组；混合收藏状态会补齐两句收藏，整组已收藏时取消两句收藏。收藏详情展示同组另一句作为上下文，学习记录仍逐句保存。
- 翻阅自动朗读及手动重播按 A、B 顺序播放，中间停顿 350ms。停顿期间仍显示播放状态；云端失败后的系统语音也在真正读完 A 后继续 B。停止、切卡、切账号、音色变化或播放不可恢复失败均取消后续句，旧回调不能启动下一句。
- 音频仍逐句复用原缓存。预加载优先当前卡的 B，再按浏览顺序展开后续卡片，维持最多五句的预加载窗口，不一次请求五组对话。
- 长对话保留纵向滚动，照片区域相应缩小，避免两句挤压或截断。没有新增熟悉度反馈。

## 前后浏览（2026-10-16）

- 左滑下一张，右滑上一张，不再表示“再看看／熟悉了”。移除评价按钮、拖动评价徽标和方向说明，底部保留独立重播。
- 每次打开建立本次浏览序列和当前位置。返回展示实际看过的卡片，连同该次出现的唯一 ID；再次前进沿用已有顺序，只有到序列前沿才补充新卡片。
- 第一张右滑回弹，不抽卡、不停止当前朗读、不产生评价；不足阈值或垂直滚动同样不导航。切换期间拒绝重复操作，完成回调校验当前卡片和账号。
- 改为连续横向翻页，不再倾斜甩出卡片或从底下抽出卡片。上一张固定在左侧，下一张固定在右侧，两张卡片随手指同速移动；松手后相邻卡片沿同一轨迹归位。反向拖动不更换预览；首张右滑有阻尼并回弹。开启“减少动态效果”时改用淡出切换。VoiceOver 提供“上一张／下一张”操作。
- 连续浏览以句子为单位随机选择，优先避开最近两张照片（按内容量缩减），再避开近期句子。照片避让优先于句子避让：即使某张照片有很多句、另一张只有一句，也尽量避免连续同图；内容不足允许重复。
- 保留近期照片加权：基础权重 12，乘以 `1 + 3 × 0.5^(回忆年龄 / 30天)` 后取整；旧照片始终有非零机会。按回忆生成时间计算，未来时间按刚生成处理。**不再读取熟悉度权重，也不再安排“再看看”的到期回访。**
- 本次照片六句模式仍先场景表达、后画面描述，每轮不重复；之后出现可滑动的“继续翻，重复听／再上传一张”卡片。左滑继续下一轮，右滑回到刚看过的最后一句。往返经过该卡片也不会重排已有顺序。
- 序列仅在本次页面生命周期中保留，不同步浏览位置；退出后下次重新抽取。历史卡片保存轻量数据，不保留每张照片的视图或解码图像。
- 收藏图标与双击收藏／取消收藏保留，仍使用实时收藏状态；与浏览导航、填空学习记录分离。首次引导同步移除旧评价按钮示意，示范左滑进入下一张。

卡片保持原有宽度，左右各露出约 10pt 的相邻卡片，拖动和归位共用相同间距。首张没有上一张，左侧不显示虚构卡片；减少动态效果模式不显示侧边预览。

## 朗读与预加载

- 每张卡片稳定出现 300ms 后自动朗读。返回上一张也重新朗读；同一卡片停留时不因普通视图刷新重复播放。底部可手动重播，顶部可关闭自动朗读。
- 导航开始立即停止旧朗读；页面切换取消上一张的延迟朗读任务，并同时校验取消状态和卡片 ID。语音服务自身的请求标识继续拦截被取消请求的迟到音频，避免快速前后滑动播放旧句。
- 回退后预加载窗口来自同一浏览序列的后续卡片，不独立随机抽取。最多预加载接下来五句；六句模式在轮次间隔卡前截断，在间隔卡暂停，进入下一轮再更新。
- 保留当前句优先、已有预加载流接管、静默串行缓存、失败冷却和音色／账号／语言隔离。预加载只缓存音频，不触发播放。
- 退出、切账号、退后台停止播放并取消或暂停预加载；回前台不突然重新自动播放。断网暂停预加载。相册选择取消后仍停留原卡片。
- 图片仍按需下载、去重、后台解码（最长边 1280），只挂载当前卡片和相邻预览。长句文字区域可垂直滚动。
- 沿用现有语音提供商、当前语言音色、本地缓存和可用的系统语音回退。对话生成仍每张照片扣一次生成次数，不按句数或对话组数收费。

## 历史数据与同步边界

- 新 `AlbumFlipDeck` 不依赖 `AlbumFlipHistoryStore`，没有评价参数、写入事件或上传回调。浏览页面不再主动刷新评价历史，也不订阅熟悉度变化。
- `AlbumFlipFeedback`、历史记录存储、`album_flip_progress` 表及 `sync_album_flip_feedback` RPC 保留，不清空、不迁移删除、不改历史内容。
- 账号生命周期中原有同步仍可上传**旧版本留下的待发送评价**、读取历史、迁移匿名历史；这不是新滑动产生的评价。新旧客户端共存时，旧客户端仍可使用原来的评价功能，新浏览不受其评价影响。
- 收藏、填空学习统计、掌握程度与生成次数不因左右滑动改变。历史数据不会被当作已浏览序列恢复。
