# 三句 · 方案 3「轻盈学习」当前功能版

## 范围

独立、可点击的 HTML 原型。保留旧方案 3 的暖白、橙色、柔和圆角、浅色选中态、轻阴影和 Avenir / 苹方字体；功能以当前 Swift 源码为准。原来的三版原型不变。

只在 `prototypes/studio-current/` 内制作，没有改动 iOS 客户端、数据库或 Edge Function，也没有提交或推送。

本地预览：http://127.0.0.1:8766/

## 演示边界

- 全部照片和句子为本地样本，默认已登录演示账号；不是用户真实数据。
- 相册选择器用三张样本照片代替系统相册；生成等待时间是演示动画，不调用 AI。
- 主题匹配用本地演示规则展示“有结果/无结果”两种状态，不等价于生产的分类或向量检索，不能据此评估匹配质量。
- 预设掌握度是演示值。每日队列与次数仅模拟同一学习范围内完成一次计数、当天再次练习不加次数；没有移植服务端完整 SRS 调度。
- 登录、注册、删除账号、购买都是本地展示，不连接账号服务、不发送邮件、不产生订单、不扣真实余额。购买面板不捏造价格，价格位置注明由 App Store 提供。
- 系统相册导出、系统通知及 Widget 安装仅展示入口/说明；网页不会申请这些真实权限。
- 朗读仅尝试浏览器提供的本地英文语音；没有可用声音时给出提示，不改用联网语音。
- 当前为中文、浅色视觉评审版，未实现全套中英文及深色皮肤。模拟器外的状态切换不是产品新功能。
- 只有自动朗读设置保存在浏览器本地。其他演示数据刷新页面后重置。

## 预览与校验

```sh
npm run dev -- --host 127.0.0.1 --port 8766 --strictPort
npm run build
node --test tests/demo-data.test.mjs
```

`npm run build` 包含 TypeScript 检查和模板完整性检查。`dist/client/index.html` 为生成的 HTML 入口，需要通过本地服务访问。

已实际在浏览器检查选图生成、两组三句、回忆保存和详情、主题标签/手动创建、无匹配空状态、填空完成、返回、再次复习、独立次数、账号入口、难度联动、刷新保留内容、离线禁选图。桌面以 393 × 852 的 App 画面评审，另检查 390px 和 320px 浏览器宽度下的可访问性。

视觉对照见 `visual-comparison.html`，检验记录见 `design-qa.md`。
