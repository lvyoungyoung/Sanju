# 三句：三种设计方向

独立的 HTML 交互原型，只探索客户端视觉与交互，不修改 Swift、后端或数据库。

## 打开方式

打开本目录的 `index.html` 可并排比较三种方案，也可进入各子目录的 `index.html` 单独体验。所有照片随原型一起保存在 `assets`，无需安装依赖或联网下载资源。

本地预览服务：

```sh
python3 -m http.server 8765 --bind 127.0.0.1 --directory prototypes/three-design-directions
```

随后打开 http://127.0.0.1:8765 。只监听本机，不发布到外网。

## 三个方向

| 方案 | 视觉重点 | 产品感受 |
| --- | --- | --- |
| 01 生活画册 | 摄影、大留白、编辑式排版 | 先爱上自己的生活，再学会描述它 |
| 02 句子手记 | 暖纸色、衬线英文、细线与摘录感 | 收藏真正想说的话，慢慢变成自己的语言 |
| 03 轻盈学习 | 明亮模块、清楚的操作、柔和圆角 | 降低学习的负担，让每一步都容易继续 |

三版均保留橙色品牌识别和“新的 / 回忆 / 学习 / 我的”导航。可以体验选图、模拟生成、“画面描述 / 生活表达”、收藏与填空学习。比较页的页面切换按钮会同步三版。

## 设计方法与边界

参考 [How to turn your AI into a world-class designer](https://www.lennysnewsletter.com/p/how-to-turn-your-ai-into-a-world)，使用其公开可读部分的方法：外部随机种子辅助发散、明确的视觉隐喻、真实图片、独立截图评审与减法设计。付费部分未阅读。没有照搬文中产品的设计。

照片来自本项目现有演示素材，不包含真实用户云端数据。原型中的句子、数量、主题及账号均为演示；生成、支付、匹配和学习记录不连接后台，不代表新的业务规则。可选的本机照片仅用于浏览器预览，不会上传，也不会被 AI 分析。朗读使用浏览器可用语音，不是 App 的最终音频效果。

这些原型用于决定方向，不是可直接替换的 SwiftUI 页面；本轮不涉及暗色模式、全部国际化状态和生产级数据持久化。

## 验证

- `node prototypes/three-design-directions/check.mjs`：检查脚本语法、本地资源、移动端配置与无后台请求。
- 浏览器核对了三版的 390px 手机布局、320px 窄屏布局和桌面对比页。
- 点测了选图、模拟生成、两组句子切换、收藏学习入口和答题反馈；轻盈版走完了一轮三句练习及完成页。
- 对比页的同步切换已验证。独立视觉评审后，收紧了首屏装饰、主题列表留白和按钮周围的间距。
- 未测试真实支付、真实模型生成和系统相册权限；这些均不在 HTML 演示范围内。没有运行或修改 iOS App。
